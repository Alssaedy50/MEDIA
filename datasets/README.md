# MEDIA Datasets

The first corpus is derived from the 51 registered Hematology knowledge records and is generated by training/build_dataset.py.

Every generated example carries:
- record_id
- task
- language
- provenance type
- generator version

Lineage:
Knowledge record → Dataset example → Tokenizer sequence → Model training

No generated example should lose its originating medical record.

Generated JSONL artifacts are intentionally produced by the reproducible generator rather than committed as opaque source files.
